# Lotto personvernside

`privacy.html` er en selvstendig side klar for GitHub Pages. Den bruker ingen
sporingsskript, eksterne fonter eller informasjonskapsler.

Publiser filen der du ønsker Lotto-siden. Åpne den faktiske offentlige adressen
og kontroller innholdet før adressen brukes i App Store Connect. Ingen side
er publisert av denne klargjøringen. Hold teksten synkronisert med
`Lotto/Views/LottoPrivacyView.swift`.
