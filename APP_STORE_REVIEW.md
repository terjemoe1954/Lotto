## Norsk beskrivelse

Lotto gir oversikt over historiske trekninger og egne rekker for Lotto,
Vikinglotto og Eurojackpot. Utforsk tallstatistikk, velg favoritttall og lag
forslag til rekker. Ukesrapporten samler valgte rekker og lar deg markere dem
som registrert. Rapporter kan skrives ut eller eksporteres til Excel.

Egne rekker, favoritter og registreringsmarkeringer kan synkroniseres mellom
enhetene dine med privat iCloud. Full backup kan eksporteres og kontrolleres.

Denne appen øker ikke vinnersjansene dine. Historiske mønstre kan ikke
forutsi neste trekning. Appen er uavhengig av Norsk Tipping.

## Review Notes (English draft)

This is an independent historical lottery statistics and personal row organizer
for Lotto, Vikinglotto and Eurojackpot. It does not sell tickets, accept stakes
or pay prizes. Row suggestions use historical statistics and/or random selection;
the onboarding explicitly states that the app does not improve winning chances.

No app account or login is required. The optional favorites setup can be skipped.
Select a game from the home screen to view history and statistics. Weekly reports
allow personal registration marks and PDF/Excel export. A registration mark is
only a personal checklist entry; it does not register a ticket with an operator.
Apple iCloud is optional; local use is supported. Settings includes the privacy
policy, contact information, backup export and isolated backup verification.
